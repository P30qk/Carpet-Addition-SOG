# Carpet SOG Addition

A configurable Carpet add-on for Minecraft, designed to enhance survival and technical gameplay by providing various useful tools, tweaks, and visualization features.

## 📖 Overview

Carpet SOG Addition (Survival & Technical Gameplay) is a Carpet mod extension that provides numerous highly customizable rules. It aims to simplify complex technical processes and reduce annoying survival mechanics.

## ✨ Features

* **Survival Tweaks:**
  * Disable natural copper oxidation.
  * Disable ice and snow melting.
  * Disable snow formation.
  * Disable lightning.
  * Disable chicken jockeys.
  * Prevent blocked beds by nitwit villagers.
  * Prevent Warden spawning.
  * Scissors (Shears) do not lose durability.
* **Technical & Farming Enhancements:**
  * Precision harvesting of Reinforced Deepslate and Suspicious Blocks.
  * Adjustable/Lockable Sculk Shrieker warning levels.
  * Additional Beacon effects.
  * Simple crafting recipes for Tinted Glass, Elytra, and Snow.
* **Fake Players (Bots):**
  * Fake players only pick up tools.
  * Configurable Fake Player rendering settings.
* **Visualization & World Eater Tools:**
  * Tweakeroo support.
  * Flexible placement for corner and triangle blocks.
  * Visualization of Sculk detection ranges and explosion ranges.
  * Creaking Heart support.
  * Ender Dragon pathfinding and block-breaking range control.
  * Wither block-breaking range control.
  * Mob spawning and wandering control.
  * World Eater Helper (Block list and tools).
  * Explosion visualization.
  * Visualization of various technical mechanics.

## ⌨️ Keybinds

| Shortcut | Action |
| :---: | :--- |
| `Ctrl + O` | Toggle the mod on/off (Master switch) |
| `Ctrl + V` | Open settings menu |
| `Ctrl + E` | Open World Eater Helper block list |

## 📋 Requirements

* **Minecraft:** `~26.2`
* **Fabric Loader:** `>=0.19.3`
* **Fabric API:** Any version (`*`)
* **Carpet Mod:** `>=26.2`
* **Java:** `>=25`

### Optional Dependencies (Recommendations)
* **Recommended:** `gca` (`*`)
* **Suggested:** `tweakeroo` (`*`)

## 🚀 Installation

1. Ensure you have Fabric Loader (`>=0.19.3`), Fabric API, and Carpet Mod (`>=26.2`) installed.
2. Download the latest `carpet-SOG-addition-[version].jar` from the [Releases](https://github.com/P30qk/Carpet-Addition-SOG/releases) page.
3. Drop the downloaded `.jar` file into your `.minecraft/mods` folder.
4. *(Optional but recommended)* Install `gca` and `tweakeroo` for the best experience.
5. Launch the game and enjoy!
